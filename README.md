# 2048 🎮

Projet de lycée retrouvé : jeu de 2048 fonctionnel avec interface graphique (Python + tkinter).

## Comment jouer

- **Windows** : exécuter `win.bat`, qui génère le jeu en `.exe` — il suffit ensuite d'ouvrir ce fichier.
- **Ubuntu** *(rajouté en retrouvant le projet)* :

```bash
chmod +x jeu2048_linux
./jeu2048_linux
```

## Contrôles

- Les **flèches directionnelles** du clavier déplacent les tuiles.
- Des **boutons fléchés** sont aussi présents sur la fenêtre du jeu et font exactement la même chose, pour jouer à la souris.
